# Python Service (FastAPI)

Standalone FastAPI microservice for analytics and intelligent features, designed to run beside your existing MERN app without changing current Node/Express functionality.

## Setup

1. Create and activate virtualenv:

```bash
cd python-service
python3 -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Configure environment:

```bash
cp .env.example .env
```

4. Run service:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8001
```

Swagger docs:

- http://localhost:8001/docs

## ML category model

Train (writes `app/ml/category_model.pkl`):

```bash
cd python-service
pip install -r requirements.txt
python -m app.ml.train_category_model
```

## Power BI reporting warehouse (PostgreSQL)

Reporting schema, ETL (Mongo → Postgres), and views for two dashboards live under:

- `sql/migrations/` — `001_reporting_schema.sql` (facts, dims, summaries), `002_powerbi_views.sql` (`vw_spending_trends`, `vw_category_ml_insights`, `vw_confidence_histogram`)
- `etl/` — `sync_expenses.py`, `transform_expenses.py`, `validate_sync.py`
- `scripts/apply_reporting_migrations.py` — apply DDL to Postgres
- `docker-compose.reporting.yml` — optional local Postgres on port **5433**

**Setup**

1. Start Postgres (e.g. `docker compose -f docker-compose.reporting.yml up -d`).
2. Set `REPORTING_DATABASE_URL` in `.env` (see `.env.example`).
3. Apply migrations: `PYTHONPATH=. python scripts/apply_reporting_migrations.py`
4. Run ETL: `PYTHONPATH=. python -m etl.sync_expenses`
5. Validate: `PYTHONPATH=. python -m etl.validate_sync`

**Tests:** `PYTHONPATH=. python -m pytest tests/` (integration test skipped unless `RUN_REPORTING_INTEGRATION=1`).

Connect Power BI Desktop to PostgreSQL and import views `vw_spending_trends` and `vw_category_ml_insights` (plus `vw_confidence_histogram` for confidence charts).

## How Node can call this service

Use HTTP from your existing backend (axios/fetch) and keep all MERN routes unchanged.

Example pattern in Node:

```js
const axios = require("axios");

const pythonApi = axios.create({
  baseURL: process.env.PYTHON_SERVICE_URL || "http://localhost:8001",
  timeout: 5000,
});

async function getCategory(description, amount, groupId) {
  const { data } = await pythonApi.post("/categorize", {
    description,
    amount,
    group_id: groupId,
  });
  return data;
}
```

Recommended integration approach:

1. Keep current Node controllers as source of truth.
2. Add optional service calls (fire-and-forget or synchronous based on feature need).
3. On Python timeout/failure, fallback gracefully to existing Node logic.
4. Add `PYTHON_SERVICE_URL` in backend `.env`.
